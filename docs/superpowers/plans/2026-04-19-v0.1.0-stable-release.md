# v0.1.0 稳定版发布过渡 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将项目从 `0.1.0-beta.x` 过渡到 `v0.1.0` 稳定版，默认发布到 npm `latest`，并补齐最小日常 CI 守门。

**Architecture:** 继续沿用现有 tag 驱动的 release workflow 作为正式发布入口，不重做构建和分发主链路。新增一个轻量常规 CI workflow，在 PR 和 `main` 上提前执行 `cargo test`、`npm pack` 和 `postinstall` skip path 验证，同时把版本号与用户文档从 beta 心智收口为 stable 默认路径。

**Tech Stack:** GitHub Actions, Rust, Node.js, npm, existing release scripts (`scripts/release-metadata.js`, `scripts/verify-release.js`, `scripts/postinstall.js`)

---
